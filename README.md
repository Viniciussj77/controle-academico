# controle-academico

## 📈 Evolução do Projeto

O projeto foi desenvolvido em duas etapas, desde a estruturação inicial até a implementação e validação do banco de dados.

### 📅 Dia 1 — Planejamento e Estruturação
- Definição dos requisitos do banco de dados.
- Modelagem das entidades e relacionamentos.
- Criação das tabelas no MySQL.
- Definição das chaves primárias e estrangeiras.

### 📅 Dia 2 — Implementação e Testes
- Inserção de dados para testes.
- Desenvolvimento de consultas SQL.
- Aplicação de restrições de integridade.
- Validação dos relacionamentos.
- Revisão do script SQL.

### 🎯 Próximos passos
- Aprimorar as consultas SQL.
- Expandir as funcionalidades do banco.
- Melhorar a documentação técnica.
